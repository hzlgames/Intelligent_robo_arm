# 直接使用方法
1. 运行智能机械臂.sln，点击左下角“诊断”按钮，在弹出的页面中点击“导入”，选择好配置文件即可，随后可以关闭诊断界面。
2. 在主界面中，选择左上方的镜头串口，点击旁边的“开始”按钮，中间的框应该会出现视频画面。此时可以测试右侧的视觉功能是否生效（测试手部识别、Gemini云端物体识别即可）
3. 在主界面中，选择右上方的机械臂串口，取消勾选下方的“模拟串口”，并点击开始，如果机械臂正常复位则说明连接成功
4. 点击主界面左下角的“SeeAndFetch”旁边的开始按钮，将手张开移入画面中，机械臂应该会追随手指尖移动
5. 使用手部引导机械臂，直到桌上物体进入画面中，此时将手势变为用食指指向物体，机械臂应该会停止移动并尝试识别。该过程由于网络和实现逻辑的问题，可能需要保持姿势半分钟以上。当画面中出现一个框选住物体的识别框时，说明已经选定成功，伸开手掌若干秒会取消选定。

*注：如果流程中发现机械臂运动方向反了，则应当在诊断页面中调整“机械标定”下，各个舵机的角度映射（回中值保持500不变，45º对应的舵机值应当变为反向偏离500，例如350改为650）

# 智能机械臂

MFC 6自由度机械臂控制软件，集成运动学、视觉（OpenCV+Google_Gemini）与模拟仿真。

## 环境配置

1.  **Visual Studio 2022**
    *   安装负载：**使用 C++ 的桌面开发 (Desktop development with C++)**
    *   必选组件：**MFC for Latest v143 build tools (x86 & x64)**

> **注意**：确保 VS 安装了 MFC 组件，否则项目无法加载。

## 依赖管理

本项目使用 **vcpkg manifest** 模式自动管理依赖。`vcpkg.json` 文件定义了所需库：
*   `eigen3` (运动学计算)
*   `opencv4[contrib]` (计算机视觉)
*   `ceres` (非线性优化)

**你不需要手动下载或配置这些库路径。**

## AI识别

需要在开启代理的情况下，在诊断页填入Gemini_API_key来启用识别功能（代理端口设置为7890）

## 编译与运行

1.  在 Visual Studio 2022 中打开 `智能机械臂.sln`。
2.  设置解决方案配置为 **Debug** 或 **Release**，平台选择 **x64**。
3.  点击 **生成 (Build)** 或按 **F5** 运行。

> **初次编译提醒**：
> VS 会自动调用 vcpkg 下载并编译所有依赖库。这可能需要 **10-30分钟**，具体取决于网络状况。请耐心等待，不要中断。

## 项目关键文件

*   `SeeAndFetchStateMachine.*`: 视觉抓取状态机逻辑
*   `MotionController.*`: 机械臂运动控制核心（因为可能产生的移动风险被删除，但是源代码保留相关逻辑）
*   `VisionService.*`: 视觉处理服务
*   `models/`: 包含 YOLO 和 MediaPipe 的 ONNX 模型文件
*   `guide_docs/`: [详细调试指南](guide_docs/)
