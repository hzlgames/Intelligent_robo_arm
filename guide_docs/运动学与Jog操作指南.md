# 运动学与 Jog / 视觉协同操控指南（最新版）

本指南按“你现在程序的真实逻辑”解释如何操控：**手动 Jog**、**视觉伺服（VS）**、**视觉识别（Vision）** 三者如何互相影响，以及如何修改“物理尺寸参数”。

---

## 1. 三条控制链路（先看这段就不迷糊了）

程序每 50ms（约 20Hz）会做一次决策：到底是谁在驱动机械臂。

### 1.1 手动 Jog（默认优先）
- **来源**：键盘 `WASD/QE/RF` 或鼠标 `JogPad`。
- **行为**：按住持续移动，松开即停。
- **优先级**：只要你手动在动，默认会 **压制视觉伺服**（除非你显式允许覆盖）。

### 1.2 视觉伺服 VS（把观测变成运动）
- **来源**：`VisionService` 产生 `VisualObservation`（或你手动点击画面产生观测）。
- **输出**：`VisualServoOutput(x,y,z,pitch)`，再喂给 `JogController` 走 IK + 下发。
- **VS 只有在满足以下条件时才会真正驱动 Jog**：
  - `VS Enable` 已勾选；并且
  - 没有勾选 `仅测试(NoDrive)`；并且
  - `覆盖手动(Override)` 已勾选 **或** 你当前没有任何手动输入（没按键/没拖摇杆）。

### 1.3 视觉识别 Vision（只负责“产出观测/叠加”）
- **Proc Enable（识别启用）**：控制视觉线程是否持续输出识别结果（目标点/框/射线等）。
- **重要**：识别启用 ≠ VS 驱动。即使识别在跑，你也可以让 VS 处于 `TEST(no drive)` 只看叠加不动机械臂。

## 2. 环境准备（建议按顺序）
1. **连接串口**：主界面顶栏选择 `COM` → 点 **“连接”**。无硬件请勾选 **“模拟”**。
2. **设置运动标定与限位**：点击底栏 **“诊断…” → “运动(Motion)”**：
   - 为 `J1..J5` 设置正确的 `ServoId`；
   - 设置合理的 `Min/Max` 软限位；
   - 若方向相反，勾选 `Invert`。
3. （可选）**启动相机**：选择相机 → 点 **“开始”**。你做视觉协同时才需要。

---

## 3. 手动 Jog（按住移动模式）

### 3.1 键盘控制（推荐）
- **沿视线前后 (Forward/Backward)**：`W` 前、`S` 后。
- **垂直于视线的上下 (Vert)**：`E` 上、`Q` 下。
- **底座转向 (Base Yaw)**：`A` 左转、`D` 右转。
- **末端俯仰 (Pitch/视角俯仰)**：`R` 抬头、`F` 低头。
- **速度**：
  - **Shift 加速**：按住 Shift 速度倍增。
  - **滑条**：右侧滑条控制线速度与俯仰速度上限。

### 3.2 鼠标 JogPad（摇杆体验）
- 在右侧黑色 **JogPad** 区域按住鼠标左键拖拽（更像 FPS 摇杆）：
  - 上下 = 沿视线前后（Forward）；左右 = 底座转向（Yaw）；拖得越远速度越大。
  - JogPad 会覆盖键盘的 Forward/Yaw（但 Vert/Pitch 仍可用键盘）。

### 3.3 安全与“为什么现在更好恢复了”
- **松手即停**：松开键盘/鼠标就不再发送。
- **空格键 Space 急停**：清空发送队列并停止（全局有效）。
- **IK 失败可恢复**：现在 IK 失败不会把内部 target “越积越远”，你反向轻推就能马上回到可达区。
- **软限位一致性**：当 IK 最佳解超出软限位时会直接判失败并停止，避免“看起来在动但实际被裁剪”的漂移感。

## 4. 视觉协同（VS + Vision）怎么用才不乱

### 4.1 只看识别、不让机械臂动（推荐先用这个验收）
1. 勾选 **Proc Enable（识别启用）**；
2. 勾选 **VS Enable**；
3. 勾选 **仅测试(NoDrive)**；
4. 选择识别算法（Auto/色块/Aruco/Detector/手等）。

效果：画面有叠加、状态栏 VS 有信息，但机械臂不会被视觉驱动。

### 4.2 让视觉真正驱动（闭环）
1. 取消勾选 **仅测试(NoDrive)**；
2. 确保你此时没有手动输入（手离开 WASD/JogPad），或勾选 **覆盖手动(Override)**；
3. 选择 VS 模式：
   - **CenterTarget**：只做居中（把目标拉到画面中心）。
   - **FollowRay**：沿指向射线推进/拉远（需要 obs.hasRay 或 depth）。
   - **LookAndMove**：先居中再推进（更像抓取策略）。
4. 调节 `advance`（推进滑条）观察前进/后退。

提示：若你一边按 `WASD` 一边开 VS，但没有勾选 Override，VS 会被压制，这是“设计如此”。

## 5. 物理尺寸参数入口（你现在可以直接改）

你可以在软件里直接改“硬件几何尺寸”，无需改代码：

### 5.1 入口位置
底栏 **“诊断…” → “几何参数”** 页。

### 5.2 可修改内容
- **连杆长度 (mm)**：`L_base/L_arm1/L_arm2/L_wrist/L_cam`（影响 FK/IK 可达性与位姿计算）。
- **FPS 安全限制（INI 可改）**：`Kinematics\\Safety` 段（用于手动 FPS 积分时的保护）：
  - `PitchMinDeg / PitchMaxDeg`
  - `ZMinMm`
  - `RMinMm / RMaxMm`
- **工具偏置（单位 mm；Cam 坐标：X右、Y下、Z前）**：
  - `J5->Cam`：末端（运动学末端点）到相机光心的偏置；
  - `Cam->Grip`：相机光心到“爪尖中心”的偏置（你提到的 40mm 在这里）。

### 5.3 保存并立即生效
点击 **“保存并应用”** 后：
- 会广播设置变更；
- 主界面会自动重新加载运动学参数，并用当前姿态估计的 FK 重置 Jog target（避免新参数导致旧 target 不可达）。

## 6. 常见问题排查（按现状重写）
- **按键 Jog 没反应**：
  - 先确认串口已连接；
  - 再检查 “诊断→运动(Motion)” 里 `ServoId` 是否配置；未配置会导致下发失败。
- **明明开了 VS 但不动**：
  - 是否勾选了 `仅测试(NoDrive)`？
  - 你是否正在按键/拖 JogPad（手动输入会压制 VS）？
  - 没勾选 Override 时，必须松开手动输入 VS 才会接管。
- **方向看起来不对/推进怪**：
  - 先去 “诊断→几何参数” 检查连杆与偏置是否正确；
  - 再确认 “诊断→运动(Motion)” 的 `Invert` 是否需要勾选；
  - 最后用小速度（滑条调低）做微调验证。
