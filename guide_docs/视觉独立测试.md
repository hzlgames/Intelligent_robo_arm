# 视觉模块独立测试指南

本文档用于验证计算机视觉 (CV) 模块的功能完整性。

## 1. 测试前提

为了在不进行机械运动的情况下安全调试视觉算法，请在主界面进行如下配置：

*   **识别启用**：勾选。启动视觉处理管线。
*   **仅测试(不驱动)**：**务必勾选**。此选项会阻断视觉坐标向运动控制器的输出，防止机械臂意外动作。
*   **VS Enable**：不勾选（此开关用于闭环伺服，单纯测试视觉时无需开启）。

## 2. 功能测试

请在主界面右侧 **“识别”** 下拉框选择对应模式进行验证。

### 2.1 目标检测 (Detector / ONNX)
*   **输入**：加载 YOLO 或其他检测网络的 ONNX 模型。
*   **预期指标**：
    *   画面正确叠加检测框 (Bounding Box)。
    *   中心点 (Center) 跟随目标移动平滑。
    *   置信度 (Conf) 显示正常。

### 2.2 ArUco 标记追踪
*   **输入**：4x4 ArUco 码。
*   **预期指标**：
    *   稳定识别 Marker ID 及角点。
    *   **深度估算**：屏幕显示 `Depth` 数值 (mm)，并能根据距离正确切换 `Near`/`Mid`/`Far` 状态。

### 2.3 手势识别 (HandLandmarks)
*   **输入**：MediaPipe Hands 模型。
*   **预期指标**：
    *   正确叠加 21 个手部骨架关键点。
    *   手势分类 (`Gesture`) 响应正确：
        *   `OpenPalm` (张开)
        *   `Fist` (握拳)
        *   `Pinch` (捏合)

## 3. 配置文件参考 (INI)

视觉参数可通过 `SettingsIo` 模块导入/导出。核心参数键值如下：

*   **全局开关**
    *   `Vision\ProcEnabled`: 1 (启用)
    *   `Vision\NoDrive`: 1 (仅测试)
*   **算法参数**
    *   `Vision\Aruco\MarkerLengthMm`: ArUco 物理边长 (默认 40)
    *   `Vision\Depth\NearMm`: 近距离阈值
    *   `Vision\Detector\OnnxPath`: 检测模型路径
    *   `Vision\Hand\PinchThreshNorm_milli`: 捏合判定阈值
