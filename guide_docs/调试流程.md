# 系统调试流程

本文档涵盖智能机械臂控制软件的核心调试步骤，包括环境验证、通信测试、视觉调试及运动控制配置。

## 1. 开发环境验证

*   **IDE**: Visual Studio 2022 (需安装 "Desktop development with C++" 及 MFC 组件)。
*   **依赖库**: 本项目采用 `vcpkg manifest` 管理依赖。
    *   **检查方式**: 编译项目。VS 应自动调用 vcpkg 安装 `eigen3`, `opencv4`, `ceres`。
    *   **验证标准**: 启动软件后，主界面状态栏显示 `cv=Y` (OpenCV 已加载)。

## 2. 串口通信调试 (Serial Port)

进入 **“诊断(D)...” -> 串口** 页面进行测试。

### 2.1 模拟通信 (无需硬件)
1.  勾选 **“使用模拟串口”**。
2.  点击 **连接**。
3.  点击 **示例Move**。
4.  **验证**: 日志栏应显示 `[TX]` (发送帧) 和 `[RX]` (模拟回复帧)，并正确解析协议包。

### 2.2 硬件联调
1.  选择对应的 `COM` 口并连接。
2.  **单轴测试**:
    *   输入 `ID` (1-6), `Pos` (目标位置), `Step` (步进)。
    *   使用 **+步/-步** 按钮点动测试。
3.  **安全限位**:
    *   测试各关节物理极限。
    *   使用 **设Min / 设Max** 按钮保存当前位置为安全边界。

## 3. 视觉系统调试 (Vision)

进入 **“诊断(D)...” -> 摄像头** 页面。

### 3.1 基础预览
*   点击 **Start** 启动预览。
*   若无摄像头，系统将自动回退至 **Test source** (测试源模式)。
*   **图像适配**: 使用 `Mirror` (镜像), `Rot` (旋转), `Crosshair` (准星) 调整画面以匹配物理安装。

### 3.2 算法验证
*   在主界面启用 **识别** 功能。
*   使用标准参照物 (ArUco 码或红色物体) 验证识别稳定性。
*   **性能指标**: 检查 `proc FPS` (处理帧率) 是否在接受范围内 (>15 FPS)。

## 4. 运动控制配置 (Motion)

进入 **“诊断(D)...” -> 运动** 页面，完成逻辑关节与物理舵机的映射。

### 4.1 关节映射
1.  **ID 绑定**: 将逻辑关节 (`J1` 底座 - `J6` 夹爪) 映射到实际舵机 ID。
2.  **同步限位**: 点击 **同步限位** 读取串口页设定的 Min/Max 值。
3.  **保存配置**: 点击 **“保存”** 将映射关系写入配置文件。

### 4.2 归位与联动
*   **归位设置**: 为各关节设定 `归位值` (Home Position)。
*   **一键归位**: 点击按钮，验证所有关节是否同步运动至设定姿态。
*   **演示脚本**: 启用 **循环** 并点击 **演示脚本**，验证多轴协调运动及指令发送频率 (Send rate)。

## 5. 参数管理

为了便于协作与状态保存，建议使用 **导入/导出参数** 功能：
*   **导出**: 将当前的标定数据 (限位、映射、视觉阈值) 保存为 `.ini` 文件。
*   **导入**: 在新环境或拉取代码后加载 `.ini` 文件，恢复调试环境。
